# 跨稿相似度指标与硬门槛

本文件定义 `fabu-deepseek-harness` 用于**保证同批稿件互不相同**的量化口径。
它是规范，不是建议：同批任意两篇不达标即返工。

---

## 一、硬门槛

| 项 | 口径 | 门槛 |
|---|---|---|
| 正文相似度 | 字符 **5-gram Jaccard**，规范化后 | 同批**任意两篇** ≤ **10%** |
| 标题相似度 | 字符 **2-gram Jaccard**，同一规范化 | 同批**任意两篇** ≤ **15%** |
| 最长公共连续片段（辅助证据） | 正文规范化后的最长逐字重合 | 报告数值；> 20 字需要人工复看 |

附加报告项：**参考相似度**（不做"必写成分剔除"的原始值），用于透明记录，不单独设门槛。

---

## 二、指标定义（可复现，平台无关）

设一篇文章的**正文**（不含标题、不含稿外说明）为 `B`。

### 第 1 步：提取实体串

从 `B` 中提取并**删除**以下两类**专有名词**——它们是 §6 H1/H2 强制重复的内容，
属于"事实要素"而非"写作"：

- 域名串：匹配 `[^\s。，、；：？！“”"'（）()]{1,30}?\.网址`
- 机构名串：匹配 `[\u4e00-\u9fffA-Za-z0-9()（）·]{2,30}?(?:股份有限公司|有限责任公司|有限公司|研究院|事务所|中心|工厂|厂)`

### 第 2 步：删除必写套语

§6 H1/H6 强制每篇都要表达、措辞容易趋同的套语，按字面删除：

```
官网已启用中文域名
仍以企业实际公开的内容为准
网站具体提供哪些功能
它处理的是名称对应与信息查找的问题
它解决的是名称对应与查找入口的问题
```

### 第 3 步：规范化

1. Unicode **NFKC** 归一化（全角→半角）；
2. 只保留**汉字**与**字母数字**，删除所有空白、换行、标点与符号；字母统一小写；
3. 得到规范化字符串 `S(B)`。

### 第 4 步：5-gram 集合

`G(B) = { S(B)[i : i+5] }`（i 从 0 起，**去重后的集合**，长度不足 5 时取整串）。

### 第 5 步：相似度

```
sim(A, B) = | G(A) ∩ G(B) | / | G(A) ∪ G(B) | × 100%
```

标题同理，但 n = **2**（标题通常只有 15–25 字，5-gram 会几乎全部落空，无法区分）。

### 门槛的含义

两篇之间凡是**连续 5 个字符以上**的重合片段，其集合重合度不得超过一成。
5 个汉字约等于一个短词组，因此这道门槛实际约束的是"**成段复用措辞与句式**"。

## 三、为什么是字符 5-gram（实测校准，非拍定）

在三组对照语料上比较候选口径。三组都按**第 2 节的同一规范化**计算，可用随技能附带的脚本一键复现：

```bash
python scripts/calibrate_metric.py            # 内置反例 6 与对照语料
python scripts/calibrate_metric.py --real 稿A.txt 稿B.txt   # 再加一组真实产出
```

实测结果（`calibrate_metric.py` 输出）：

| 对照语料 | 5-gram | 8-gram | 10-gram | 15-gram | `difflib` ratio | 最长重合 | 标题 2-gram |
|---|---|---|---|---|---|---|---|
| **真正不同**（真实产出：途度检测 ↔ 净浮生） | **0.62%** | 0.00% | 0.00% | 0.00% | 7.75% | 7 字 | **5.56%** |
| **换词式同质**（反例 6 的完整稿） | **47.90%** | 36.72% | 31.11% | 20.66% | 83.06% | 43 字 | **16.67%** |
| **明确不同**（对照样本） | **0.00%** | 0.00% | 0.00% | 0.00% | 21.11% | 4 字 | **7.41%** |

结论：

1. **5-gram 可用。** 真不同 0.62%、明确不同 0.00%，而同质 47.90%；10% 门槛落在两者之间，
   余量在 16 倍以上，不存在"改几个词就能压下去"的空间。
2. **8-gram 及以上过于宽松。** 对两组真正不同的稿件都给 0.00%，等于只能发现 8 字以上的逐字照抄，
   对"换了词、留了骨架"的稿件完全失效。故取 **5-gram**。
3. **`difflib.SequenceMatcher` 不可用于中文。** 真不同给 7.75%，而**明确不同的对照给 21.11%**——
   排序自相矛盾，两组都贴着 10% 门槛，既不具区分力又会误杀正常稿。
   因此本技能**明确不使用**该口径，任何实现都不得用它替代。
4. **标题只用 bigram，且余量更窄。** 合格样本 5.56%／7.41%，同质样本 16.67%，门槛取 **15%**。
   标题通常只有 15–25 字，bigram 集合很小，数值本身噪声较大，
   所以标题**不能只靠这个数字把关**，必须同时执行 `editorial-checklist.md` C1（标题句式明显不同）。

> 若将来发现"换词式同质"这一组的分数掉到 10% 附近，说明指标或规范化实现已经退化，
> 应重新校准后再使用，而不是放宽门槛。

## 四、参考实现

- [`scripts/similarity_check.py`](../scripts/similarity_check.py) —— 门槛检查（交付前必跑）
- [`scripts/calibrate_metric.py`](../scripts/calibrate_metric.py) —— 阈值校准复现（改动指标后必跑）

纯标准库，无第三方依赖、无网络、无平台绑定：

```bash
# 扫描整个项目文件夹（递归查找文件名含"稿件"的 .txt，跳过稿外说明/来源/科普）
python scripts/similarity_check.py --dir "<项目文件夹>"

# 指定文件
python scripts/similarity_check.py 稿A.txt 稿B.txt 稿C.txt

# 补充实体串（自动识别不理想时）
python scripts/similarity_check.py --dir "<文件夹>" --entities "某某有限公司" "某某.网址"
```

- 退出码 `0` = 全部达标；`1` = 存在超门槛的配对；`2` = 用法错误或找不到可比稿件。
- 只有 1 篇稿件时不做跨稿比较，直接返回 0（单篇检查见 `editorial-checklist.md` B 节）。

**任何实现都可以，只要第 2 节的五步口径一致。** 换语言、换库只要口径相同，结论就应相同；
若结论不同，先核对规范化步骤（尤其 NFKC、标点删除、实体串与必写套语剔除）。

## 五、不达标时的整改流程

**不要用同义词替换**——那正是反例 6，实测会把相似度推到 40% 以上。

按下列顺序改，改完重跑指标：

1. **换开篇类型**：行业消息开篇 ↔ 企业事件/环节开篇 ↔ 消费场景开篇。
2. **换报道问题**：重新回答"这篇要回答什么"。问题不同，段落自然不同。
3. **换段落推进链**：调换段落顺序，或增删一个中间环节（例如把"政策背景"从第 1 段挪到第 4 段）。
4. **换论证路径**：行业→企业→环节→域名 ↔ 环节→企业→政策→域名。
5. **换结尾落点**：报告落款 / 台账栏目 / 包装与商品页 / 交接单——不要都用"迈向……"式收尾。
6. **换句式**：连续出现的"对……来说，这是……的一种方式""它处理的是……的问题"这类句式，
   至少在一半段落里换掉。

改完仍不达标，通常说明**两篇的报道问题实质相同**，应回到 §5.1 重新选题，而不是继续磨字句。

## 六、这道门槛**不能**证明什么（诚实边界）

- 它测的是**字面重合**，不是**语义或结构同质**。
  一篇把论证路径、段落顺序、结尾方式都照搬、只把每句话重写一遍的稿子，
  在这道门槛上可能拿到 0%，但读起来仍然是同一篇。
- 因此它是**必要而非充分**条件：必须与 `editorial-checklist.md` C 节（C1–C10）的**定性检查**
  同时执行，两者都过才算达标。
- 门槛只约束**同批内部**。与批次之外的历史稿件、与网络上既有文章的重合不在本门槛范围内。
- 阈值是经验校准值，不是行业标准。换语言、换文体（如英文、长文）需重新校准后再使用。
